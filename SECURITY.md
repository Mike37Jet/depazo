# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad en depazo, **no abras un issue público**.

Repórtala de forma privada desde la pestaña **Security → Report a vulnerability** de este repositorio (GitHub Private Vulnerability Reporting). Incluye:

- Descripción del problema y su impacto.
- Pasos para reproducirlo.
- Versión o commit afectado.

Respondemos en un plazo de 7 días y te mantendremos informado hasta que el problema quede resuelto. Agradecemos la divulgación responsable: por favor, no publiques los detalles hasta que haya una corrección disponible.

## Alcance

- La PWA, la API y el proceso de ingesta de este repositorio.
- No incluye los portales inmobiliarios de terceros ni los servicios de Supabase, Cloudflare o Google Cloud. Esos se reportan a sus respectivos dueños.

## Versiones soportadas

Solo la última versión de la rama `main` recibe correcciones de seguridad.
